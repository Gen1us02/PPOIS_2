## ⚗️ Лабораторная работа №4

### Вариант 42

Предметная область: создание и использование робототехнических систем.

Важные сущности: робот, сенсоры, программное обеспечение, механизмы, энергозависимость, управление.

Операции: операция программирования робота, операция взаимодействия с окружающей средой, операция обучения, операция технического обслуживания, операция управления и мониторинга.

## Стек технологий

- Django
- requests
- PostgreSQL
- Bootstrap


## 📌 О программе
Программа представляет собой веб-интерфейс для [Лабораторной работы №1](https://github.com/Gen1us02/PPOIS_2/tree/main).

### Система управления роботом способна:
- Управлять роботом и перемещать его в различных направлениях при этом изменяя значения на сенсорах
- Взаимодействовать с окуружающей средой подбирая предметы
- Считывать данные с установленных сенсоров ( на выбор температурный, сенсор расстояния, GPS-сенсор, оптический). У каждого сенсора данные обновляются в соответствии с действиями робота (температурный сенсор - парсит данные с [сайта](https://openweathermap.org/) для города Минск, дистанционный и GPS - при передвижении робота, оптический - симулирует изменение количества объектов перед роботом)
- Обучаться новым фразам и произносить их
- Заряжаться
- Подвергаться износу и ремонтироваться
- Устанавливать на робота руки и ноги
- Устанавливать на робота сенсоры
- Устанавливать ПО для робота

## Общий код с ЛР1

Веб-интерфейс использует все реализованные сущности, используемые в моделях БД и имеет расширенный функционал по сравнению с ЛР1 (установка механизмов и сенсоров для роботов, симуляция изменений температурного и оптического сенсоров).

## Инструкция по запуску

Надо определить переменные окуружения в соответствии с файлом .env.example

```sh
git pull https://github.com/Gen1us02/PPOIS_2.git lab4
pip install -r requirements.txt
python manage.py makemigrations
python manage.py migrate
# Надо загрузить в БД все фикстуры
python loaddata fixtures/имя_приложения/имя_фикстуры
python manage.py runserver
```

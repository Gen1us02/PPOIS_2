## 💻 Демонстрация работы программы

При запуске программы пользователю предлагается выбор: загрузить записи из БД или загрузить данные из файла.

![Начальный экран](images/main_window.png)

При выборе пользователем варианта загрузки записей из файла, пользователю показывается диалоговое окно, где он выбирает файл для загрузки

![Диалог загрузки файла](images/choose_read_file.png)

Если же пользователь выбрал загрузку записей из БД, то никакого диалогового окна он не увидит и ему покажется заполненная таблица с записями

![Загрузка записей из БД](images/db_write.png)

После загрузки данных, пользователю предоставляется возможность работы с этими данными: производить поиск, удаление, добавления и просмотра дерева записей.

### Поиск записей

При нажатии на кнопку "Поиск студентов" пользователю отображается окно с фильтрами для поиска

![Поисковое окно](images/search_window.png)

Пользователь может по этим фильтрам получить нужных ему студентов. При правильной настройке фильтров пользователю высвечивается уведомление о количестве найденных записей.

![Пример поиска](images/succesful_search.png)

И вывод этих записей в постраничном виде

![Результат поиска](images/search_records.png)

При неправильной настройке фильтров, пользователю высветится уведомление о том, что он сделал не так.

![Ошибка поиска](images/search_error.png)

### Дерево студентов

При нажатии на кнопку "Показать дерево студентов", пользователю отображается дерево студентов, где корни это номера групп студентов, а листья сами студенты

![Дерево студентов](images/students_tree.png)

При этом кнопка "Показать дерево студентов" заменяется на кнопку "Скрыть дерево студентов", которая уже ведет на экран с постраничным отображением записей студентов.

### Удаление студентов

При нажатии на кнопку "Удаление студентов", пользователю отображается диалоговое окно с фильтрами для удаления студентов.

![Окно удаления](images/delete_window.png)

При правильной настройке фильтров пользователю отобразится уведомление о том, сколько записей было удалено.

![Успешное удаление](images/delete_successful.png)

При неправильной настройке фильтров пользователю отобразится уведомление о неправильной настройке фильтров с сообщением об ошибке.

![Ошибка удаления](images/delete_error.png)

При закрытии окна пользователю предоставляется выбор о сохранении изменений в файл.

![Сохранение изменений](images/saving_changes_delete.png)

При выборе нажатии кнопки "Yes", пользователю отображается диалог выбора файла. Он такой же как и при выборе файла загрузки.

### Добавление студентов

При нажатии на кнопку "Добавление студентов" пользователю отображается диалоговое окно с полями для ввода информации о студенте.

![Окно добавления](images/add_students.png)

При выборе группы для студента ниже динамически подружаются экзамены для выбранной группы.

![Экзамены группы](images/group_exams.png)

Далее при правильном заполнении формы пользователю отображается уведомление о успешном добавлении студента.

![Успешное добавление студента](images/successful_add.png)

Если же форма была заполнена некорректно, пользователю отображается уведомление об ошибке ввода.

![Ошибка добавления](images/add_error.png)

При закрытии окна пользователю также предлогается сохранения записей в файл (см. Удаление студентов)
